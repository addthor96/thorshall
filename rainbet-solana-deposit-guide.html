Why Is My Rainbet Solana Deposit Pending?

Exchange Delay

If you sent SOL from an exchange, the transaction might be queued before it even reaches the Solana network.

Wrong Network Or Token

Sending the wrong asset, unsupported token, or wrong network can prevent funds from appearing normally.

Address Mistake

Even one wrong character can send funds to the wrong destination. Always copy and verify the address.

Common Solana Deposit Mistakes To Avoid

  • Sending crypto before confirming Rainbet supports that exact asset and network
  • Sending SPL tokens when the page expects native SOL
  • Copying an old wallet address from a screenshot or browser history
  • Ignoring minimum deposit requirements
  • Using an exchange without checking withdrawal status
  • Sending a large first deposit without testing a small amount
