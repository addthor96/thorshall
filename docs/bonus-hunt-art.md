# Stream artwork

The custom overlay background is `img/bonus-hunt-storm-v2.jpg` (1024 × 1536), generated with the built-in image generation tool and encoded as JPEG for web delivery. Its original PNG is retained in the local working folder.

Creative prompt: luxury Norse fantasy portrait overlay background, obsidian stone, antique gold knotwork edging, subtle teal stormlight, a stormlit Viking hall and hammer crest concentrated at the top, with a quiet dark central space for legible live data. Opaque background; no text, logos, watermark or fake UI elements.

All live numbers, slot names, payout highlights, and scrolling are real HTML and JavaScript layered over the illustration. The artwork does not contain placeholder numbers or labels. The surrounding Browser Source canvas remains transparent.
